# EV Battery Rain Protection System

## Overview
This project is a smart rain-protection mechanism designed for electric scooters. The system detects rainfall and automatically deploys a protective cover over the battery compartment to prevent water ingress and improve battery safety.

## Problem Statement
Electric scooter batteries are vulnerable to water exposure during heavy rain. Water ingress may affect battery performance and safety.

## Proposed Solution
A rain sensor detects rainfall and activates a motor-driven retractable cover. The cover automatically opens during rain and retracts when conditions are dry.

## Features
- Automatic rain detection
- Motorized battery cover deployment
- Improved battery protection
- Low-cost implementation
- Suitable for electric scooters

## Components Used
- Rain Sensor
- DC Motor
- Battery
- Relay Module
- Protective Cover Mechanism

## Working Principle
1. Rain sensor detects water droplets.
2. Sensor sends signal to control circuit.
3. Motor activates and deploys protective cover.
4. Cover shields battery compartment.
5. Cover retracts when rain stops.
